PROJETO: GRIT ENGINE

GRIT Engine: simulação de partículas WebGL2 em alta escala

Publicado em 09/04/2026 • Leitura estimada: 6 min

O GRIT Engine foi desenhado para cenários interativos com dezenas de milhares de partículas, sem acoplamento a framework. O núcleo em TypeScript oferece uma API imperativa clara para integração em React, Vue, Svelte ou JavaScript puro.

Arquitetura orientada a throughput

  • SpatialGrid para busca local de vizinhos sem custo quadrático.
  • Instancing GPU no WebGL2 para reduzir overhead de draw calls.
  • Reuso de arrays no hot path para controlar pressão de GC.
  • Presets de execução e orçamento adaptativo de partículas.
  • Fallback de backend (offscreen-worker -> webgl2 -> canvas2d) para resiliência.

Integração segura e previsível

Contratos tipados (GritEngineOptions, SimConfig) reduzem ambiguidade nas integrações e aceleram onboarding técnico. Isso facilita evolução do produto sem quebrar consumidores.
