PROJETO: AIRPORT BUS

Airport Bus: operações aeroportuárias realtime com Phoenix e Vue

Publicado em 09/04/2026 • Leitura estimada: 6 min

O Airport Bus centraliza operações críticas com abordagem realtime-first. A combinação entre API em Phoenix, autenticação stateless e frontend Vue 3 garante fluxo claro para operação diária e evolução segura do produto.

Fluxo principal de execução

  1. Frontend autentica com POST /api/auth/login.
  2. Backend valida credenciais e emite token assinado com Phoenix.Token.
  3. Rotas privadas passam pelo plug de autorização.
  4. Regras de negócio ficam centralizadas no contexto Ops.
  5. Eventos são publicados em ops:lobby para atualização sem refresh.

Escolhas de engenharia com foco operacional

  • Contexto de domínio único para reduzir duplicação de regra em controllers.
  • Channels como mecanismo nativo de realtime com boa relação custo/valor.
  • Pipeline shell de validação com relatórios versionados em docs/reports/.
  • Separação backend/frontend para deploy independente.
