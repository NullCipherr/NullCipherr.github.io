# Calendário Editorial Técnico (Fase 4)

## Objetivo

Sustentar crescimento orgânico com conteúdo técnico conectado aos serviços e projetos do portfólio.

## Premissas

- Cadência quinzenal.
- Cada artigo deve apontar para pelo menos 1 projeto e 1 CTA de contato.
- Atualização trimestral dos artigos pilar com novos aprendizados e links.

## Trilhas temáticas

1. Front-end e SEO técnico
2. Backend Python e dados
3. Games e arquitetura multiplayer

## Planejamento (12 semanas)

| Semana | Tema principal | Palavra-chave foco | Intenção | Link interno obrigatório |
| --- | --- | --- | --- | --- |
| 1 | Arquitetura front-end para landing + blog | arquitetura front-end escalável | Descoberta | `#projetos` + contato |
| 3 | SEO técnico para portfólio de desenvolvedor | seo técnico portfólio | Descoberta/consideração | Artigo pilar front-end |
| 5 | Pipelines de dados em Python | pipeline python produção | Consideração | Projeto backend |

## Checklist de publicação por artigo

- Title e meta description únicos.
- Canonical e Open Graph definidos.
- JSON-LD `BlogPosting` válido.
- Link para 1 projeto da home.
- Link para 1 artigo relacionado.
- CTA final de contato contextual.

## Rotina de manutenção

1. Revisar Search Console e páginas com maior impressão a cada 15 dias.
2. Atualizar interlinks quando novos artigos entrarem.
3. Revisar conteúdos pilar a cada 90 dias.
4. Registrar oportunidades de novos tópicos no roadmap.
