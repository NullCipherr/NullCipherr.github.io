# Security Policy

## Supported Versions

This repository is actively maintained on the `main` branch.

| Version | Supported |
| --- | --- |
| `main` (produção atual) | ✅ |
| older versions / snapshots | ❌ |

## Reporting a Vulnerability

If you identify a security vulnerability, do not open a public issue with sensitive details.

Use one of the channels below:

- GitHub (perfil): `https://github.com/NullCipherr`
- E-mail: `blendsteal@gmail.com`

Please include:

- a clear vulnerability description;
- reproduction steps;
- potential impact;
- a suggested fix (if available).

## Response Timeline

- Acknowledgment: up to 5 business days.
- Initial assessment: up to 10 business days.
- Fix and disclosure: based on severity and complexity.

## Scope

This policy covers assets in this repository, including:

- static pages (`index.html`, `404.html`, blog);
- front-end scripts in `js/`;
- styles in `css/`;
- SEO configuration (`robots.txt`, `sitemap.xml`).

It does not cover third-party services outside this project's control (for example, GitHub infrastructure).
